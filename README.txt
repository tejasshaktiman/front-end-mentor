### What I learned

In this project, I practiced centering a card component in the viewport and structuring simple card layouts with CSS Flexbox:

```css
body {
  display: flex;
  justify-content: center;
  align-items: center;
  background-color: rgb(213, 225, 239);
}

.card {
  display: flex;
  flex-direction: column;
  border-radius: 10px;
  background-color: white;
}
